# Soup Club (`soupclub.ch`)

Static website for Soup Club at Amboss Rampe (Zollstrasse 80, 8005 Zürich), hosted on GitHub Pages.

## How Elena can update the website (no code required)

1. Open `https://soupclub.ch/#edit` in any web browser.
2. Update any text fields (German and/or English), dates, photo, or **Weekly menu** items.
   - To display the weekly menu on the page, check **Show weekly menu when entries exist** and add one menu item per line.
3. Click **Apply to preview** to check the result, then click **Download updated website** (this saves `index.html`).
4. Open [Upload files to `main`](https://github.com/JibidyOS/soupclub-site/upload/main), drag the downloaded `index.html` file into the upload box, and click **Commit changes**.
5. GitHub Pages automatically republishes the site within ~1 minute.
